outputs. R1–R5 each has a completion gate. Project facts/approvals, Markdown
sequencing, focused skills and executable tools have distinct ownership. Context

acceptance, the existing three-skill install, absent MCP implementation and planned

without a universal engine. No generic orchestration engine is needed for Laifen.
